    Box

    Create a box from explicit dimensions or optional input bounds, with the declared primitive and topology controls.

    Documentation edition
    2026-10-19
    Operation version
    5

    This page documents this exact operation version. Documentation edition and backend implementation versions are separate. All declared parameters are listed. Behavioral explanations and effect media are tracked separately.

    Inputs and outputsParameters (20)Examples and verification

    Inputs and outputs

    Inputs

    1. bounds_source Geometry optional

    Outputs

    1. mesh Geometry

    Contract fields come from a dated Catalog snapshot. Soft slider endpoints do not define hard validation limits. Numeric defaults use a readable display precision; exact typed values remain in the downloadable contract.
