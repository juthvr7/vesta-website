    Heightfield processing / Node reference

    Parameter guide · v1

    heightfield_noise

    Generate layered procedural noise in a named heightfield layer with optional masking and domain warping.

    Documentation edition
    2026-10-19
    Operation version
    1

    This page documents this exact operation version. Documentation edition and backend implementation versions are separate. All declared parameters are listed. Behavioral explanations and effect media are tracked separately.

    Inputs and outputsParameters (31)Examples and verification

    Inputs and outputs

    Inputs

    1. heightfield Geometry required
    2. mask Geometry optional

    Outputs

    1. heightfield_0 Geometry
