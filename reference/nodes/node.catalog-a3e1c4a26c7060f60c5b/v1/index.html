    Gamma

    Remap height samples or image channels with a manual gamma curve or mean-based automatic correction.

    Usage notes

    • Manual correction uses a quantized curve; automatic correction uses continuous input levels. Finite negative and HDR samples are accepted; final outputs are normalized to zero through one.
    • Automatic can change color balance because each channel is corrected independently, rather than using one luminance curve.
    • Gray images stay gray. RGB stays RGB. RGBA input yields RGB with alpha removed, without premultiplication. Alpha is not a mask; even transparent pixels contribute their color values.
    • The examples below are terrain outputs. Color-image controls and transport are verified separately; the terrain renders are not presented as image-input or GPU evidence.

    Inputs and outputs

    Inputs

    1. heightfield_0 Geometry required

      One required Geometry input containing one heightfield or one typed Gray/RGB/RGBA image. Arbitrary volumes, meshes and mixed primitive containers are rejected.

    Outputs

    1. heightfield_0 Geometry

      Corrected heightfield or image. Heightfield layers and image identity/grid metadata are retained; RGBA becomes RGB.

    GammaValue #

    GammaValue

    Manual curve control, shown when Automatic is off. One preserves normalized levels, zero produces black, values between zero and one lower intermediate values, and values above one raise them. Toggling Automatic keeps the stored manual value.

    Type
    ScalarF64
    Default
    0.44
    Range endpoints
    0 (soft) → 4 (soft)

    Automatic #

    Automatic

    Derive the curve from the input arithmetic mean. For a nondegenerate normalized channel, that input level maps to one half. RGB channels use separate means; GammaValue is hidden and ignored. A completely black channel becomes white at the defined zero-mean boundary.

    Type
    Bool
    Default
    false
