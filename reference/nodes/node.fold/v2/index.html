    Fold · Node reference

    Fold height through sine, triangle and sawtooth profiles. Repetition and symmetry can turn the same starting terrain into very different shapes.

    Documentation edition
    2026-10-19
    Operation version
    2

    This page documents this exact operation version. Documentation edition and backend implementation versions are separate.

    Inputs and outputsParametersExamples and verification

    Inputs and outputs

    Inputs

    1. heightfield required

      Required terrain heightfield.

    2. folds optional

      Optional per-sample frequency modulation. Its grid resolution must match the terrain; it is not an output opacity mask.

    Outputs

    1. heightfield_0

      Height values remapped through the selected waveform.

    Parameters

    Contract fields come from a dated Catalog snapshot. Soft slider endpoints do not define hard validation limits. Numeric defaults use a readable display precision; exact typed values remain in the downloadable contract.

    WaveformFoldsSymmetric

    Waveform #

    Waveform

    Select Sine, Triangle or Sawtooth. The result study compares all three using the same terrain and display treatment.

    Type
    Choice
    Default
    Sine
    Accepted values
    Sine / Triangle / Sawtooth

    Folds #

    Folds

    Controls waveform frequency across the height range. The optional second input modulates this frequency per sample.

    Type
    Number
    Default
    2
    Range endpoints
    0 (soft) → 10 (soft)

    Symmetric #

    Symmetric

    Offsets the waveform input around the height midpoint before folding. It changes the profile alignment rather than blending the result.

    Type
    Boolean
    Default
    On
