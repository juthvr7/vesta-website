    Erosion / Node reference

    Parameter guide · v1

    Erosion2

    Erode a heightfield and publish height, flow, deposits and wear. Optional precipitation and the inhibitor recipe modulate particle spawning.

    Documentation edition
    2026-10-19
    Operation version
    1

    This page documents this exact operation version. Documentation edition and backend implementation versions are separate. All declared parameters are listed. Behavioral explanations and effect media are tracked separately.

    Inputs and outputsParameters (22)Examples and verification

    Usage notes

    • The current CPU solver requires a nonempty square grid. Backend selection belongs to the host evaluation request, not to these author parameters. The separate engine-delivery study records its own CPU / GPU scope.

    Inputs and outputs

    Inputs

    1. heightfield_0 Geometry required
    2. heightfield_1 Geometry optional

    Outputs

    1. heightfield_0 Geometry
    2. flow Geometry
    3. deposits Geometry
    4. wear Geometry
