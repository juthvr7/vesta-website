    Geometry and node tools

    Terrain is one part of Vesta. Existing node registrations also cover geometry creation, topology, attributes, groups, curves, volumes and UVs. Browse the full Catalog below; implementation and documentation status are shown separately.

    Starts with
    Typed geometry and its point, vertex, primitive and detail attributes; explicit parameters.
    Produces
    Geometry and data that continue through the same Graph, asset and engine-delivery contracts.
