    Data and execution

    Heightfields, masks and other spatial data pass through the same typed Graph and Executor. Hosts convert user intent to this shared model instead of owning separate operation semantics.

    Starts with
    Typed spatial data and a bounded, explicit request.

    Typed spatial data

    Keep distinct data meanings explicit, even when data shares raster storage.

    CPU and GPU capabilities

    Backend support belongs to an operation implementation. A GPU stage elsewhere in a chain does not make every operation GPU-verified.

    Read verification in context

    Read the host, backend, version, resolution and date together. A picture shows appearance; numerical and interaction records establish different kinds of evidence.
