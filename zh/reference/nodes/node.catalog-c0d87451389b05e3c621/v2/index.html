    Attribute Delete

    从完整Geometry容器移除选定属性，保留元素身份和拓扑。

    文档版本
    2026-10-19
    节点逻辑版本
    2

    本页对应这个确切的节点逻辑版本。文档打包版本与后端实现版本分别记录。 保留全部已声明参数；行为说明和效果媒体分别记录完成状态。

    输入与输出参数 (11)效果示例与验证

    使用提示

    • 参考输入只读；选择属性不会删除点或图元。

    输入与输出

    输入

    1. geometry Geometry 必需
    2. reference Geometry 可选

    输出

    1. geometry Geometry

    参数

    契约字段来自有日期的Catalog快照。滑块软范围端点不等于硬验证范围。 数值默认值采用便于阅读的显示精度，精确值保留在可下载契约中。
