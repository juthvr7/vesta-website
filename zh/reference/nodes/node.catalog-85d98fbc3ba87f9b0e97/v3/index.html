    输入与输出参数 (18)效果示例与验证

    当前实现限制

    • points — every mesh point is rasterized; group filtering is not implemented
    • filterbysrcattrib — source-attribute filtering is not implemented
    • srcattrib — source-attribute filtering is not implemented
    • fogvolumes — volume naming is fixed by the kernel
    • filter — the kernel accumulates point values without a reconstruction filter
    • particlescale — point splat radius is one voxel
    • minfilter — the kernel accumulates point values without a reconstruction filter
    • velocityblur — velocity blur is not implemented
    • shutter — velocity blur is not implemented
    • shutteroffset — velocity blur is not implemented
    • blursamples — velocity blur is not implemented
    • densityattrib — coverage weighting is not implemented
    • densityscale — coverage weighting is not implemented
    • normalize — coverage normalization is not implemented
    • attribute# — per-attribute rasterization rules are not implemented
    • rule# — per-attribute rasterization rules are not implemented

    输入与输出

    1. geometry Geometry 必需

    输出

    1. volume_0 Geometry
