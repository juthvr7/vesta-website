    Terraces · 节点参考

    在已有高度场上形成台阶、崖壁与重复岩层。保留地形的起点，改变坡面的结构与性格。

    文档版本
    2026-10-19
    节点逻辑版本
    2

    本页对应这个确切的节点逻辑版本。文档打包版本与后端实现版本分别记录。

    输入与输出参数效果示例与验证

    输入与输出

    输入

    1. heightfield_0 必需

      待塑形的地形高度场。

    输出

    1. heightfield_0

      按Intensity混合层状高度轮廓后的高度场。

    参数

    契约字段来自有日期的Catalog快照。滑块软范围端点不等于硬验证范围。 数值默认值采用便于阅读的显示精度，精确值保留在可下载契约中。

    NumTerracesUniformitySteepnessIntensitySeed

    NumTerraces #

    NumTerraces

    构建岩台轮廓的层数。求值至少需要两层，并受请求的资源预算约束。

    类型
    整数
    默认值
    10
    范围端点
    3 (软范围) → 256 (软范围)

    Uniformity #

    Uniformity

    控制层级分布的均匀程度；非均匀层级的可重复变化由Seed控制。

    类型
    数值（浮点）
    默认值
    0.6
    范围端点
    0 (软范围) → 1 (软范围)

    Steepness #

    Steepness

    塑造层级之间的过渡。固定层数后调整，更容易观察坡面轮廓的变化。

    类型
    数值（浮点）
    默认值
    0.2
    范围端点
    0 (软范围) → 1 (软范围)

    Intensity #

    Intensity

    在原地形与分层轮廓之间混合。零保留输入，一完整应用分层轮廓。

    类型
    数值（浮点）
    默认值
    1
    范围端点
    0 (软范围) → 1 (软范围)

    Seed #

    Seed

    非均匀层级表的显式种子；相同输入和执行条件遵循确定性契约。

    类型
    整数
    默认值
    0
    范围端点
    0 (软范围) → 65535 (软范围)
