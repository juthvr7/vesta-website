    输入与输出参数效果示例与验证

    输入与输出

    输入

    1. heightfield_0 必需

      Geometry输入承载的地形高度场。

    输出

    1. heightfield_0

      按所选边界轮廓衰减外围后的地形。

    参数

    契约字段来自有日期的Catalog快照。滑块软范围端点不等于硬验证范围。 数值默认值采用便于阅读的显示精度，精确值保留在可下载契约中。

    StyleSizePixelsSoftness

    Style #

    Style

    选择Round、Square或Precise。Round使用柔化的径向边界，Square使用矩形轮廓，Precise按像素保留明确边缘带。

    类型
    选项
    默认值
    Square
    允许值
    Round / Square / Precise

    Size #

    Size

    控制Round和Square的边界轮廓。Precise改用Pixels；比较范围时应使用同一输入。

    类型
    数值（浮点）
    默认值
    0.5
    范围端点
    0 (软范围) → 1 (软范围)

    Pixels #

    Pixels

    设置Precise模式的整数像素边距，不影响Round或Square。若边距使遮罩成为常量，结果会归零。

    类型
    整数
    默认值
    2
    范围端点
    1 (软范围) → 500 (软范围)

    Softness #

    Softness

    柔化Round遮罩，不影响Square或Precise；比较此参数时应保持模式一致。

    类型
    数值（浮点）
    默认值
    0.25
    范围端点
    0 (软范围) → 1 (软范围)
