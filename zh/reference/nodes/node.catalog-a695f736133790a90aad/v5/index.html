    逐参数使用说明 · v5

    Box

    根据显式尺寸或可选输入范围创建立方体，并使用已声明的图元与拓扑控制。

    文档版本
    2026-10-19
    节点逻辑版本
    5

    本页对应这个确切的节点逻辑版本。文档打包版本与后端实现版本分别记录。 保留全部已声明参数；行为说明和效果媒体分别记录完成状态。

    输入与输出参数 (20)效果示例与验证

    输入与输出

    输入

    1. bounds_source Geometry 可选

    输出

    1. mesh Geometry

    参数

    契约字段来自有日期的Catalog快照。滑块软范围端点不等于硬验证范围。 数值默认值采用便于阅读的显示精度，精确值保留在可下载契约中。

    Primitive Type #

    primitive_type

    选择已声明的立方体图元类型，同时决定哪些拓扑控制生效。

    类型
    Text
    默认值
    poly
    允许值
    poly / polymesh / mesh / nurbs / bezier / points / prim

    Connectivity #

    connectivity

    曲面采样的连接方式：行、列、三角形或四边形。

    类型
    Text
    默认值
    quads
    允许值
    rows / cols / rowcol / triangles / quads / alttriangles / revtriangles
    条件与重复行

    禁用／隐藏条件

    {
  "disableWhen": "ch(\"primitive_type\") == \"poly\"",
  "hideWhen": null
}

    Consolidate Corner Points #

    consolidate_corner_points

    在适用类型中合并各侧面重合的角点。

    类型
    Bool
    默认值
    true

    Size #

    size

    三个局部轴方向的完整尺寸。

    类型
    Vector3
    默认值
    [1,1,1]
    范围端点
    -1 (软范围) → 1 (软范围)

    Center #

    center

    立方体旋转前的中心位置。

    类型
    Vector3
    默认值
    [0,0,0]
    范围端点
    -1 (软范围) → 1 (软范围)

    Rotate #

    rotate

    生成立方体的旋转角度。

    类型
    Vector3
    默认值
    [0,0,0]
    范围端点
    0 (软范围) → 360 (软范围)

    Uniform Scale #

    uniform_scale

    统一倍乘立方体的各向尺寸。

    类型
    ScalarF64
    默认值
    1
    范围端点
    0 (软范围) → 10 (软范围)
