    逐参数使用说明 · v3

    Heightfield Blur

    过滤指定高度场图层，可使用独立的遮罩输入。

    文档版本
    2026-10-19
    节点逻辑版本
    3

    本页对应这个确切的节点逻辑版本。文档打包版本与后端实现版本分别记录。 保留全部已声明参数；行为说明和效果媒体分别记录完成状态。

    输入与输出参数 (9)效果示例与验证

    输入与输出

    输入

    1. heightfield Geometry 必需
    2. mask Geometry 可选

    输出

    1. heightfield_0 Geometry

    参数

    契约字段来自有日期的Catalog快照。滑块软范围端点不等于硬验证范围。 数值默认值采用便于阅读的显示精度，精确值保留在可下载契约中。

    Blur LayerMask LayerMask Aware BlurIterationsMethodRadiusOverride BorderBorder ValueSharpen Strength

    Blur Layer #

    layer

    需要过滤的命名图层。

    类型
    Text
    默认值
    height
    条件与重复行

    参数组: General

    Mask Layer #

    masklayer

    影响遮罩的图层名；可选第二输入可提供遮罩数据。

    类型
    Text
    默认值
    mask
    条件与重复行

    参数组: General

    禁用／隐藏条件

    {
  "disableWhen": "ninputs(\"mask\") == 0",
  "hideWhen": null
}

    Mask Aware Blur #

    maskaware

    过滤时计入遮罩权重，替代对邻域一视同仁。

    类型
    Bool
    默认值
    false
    条件与重复行

    参数组: General

    禁用／隐藏条件

    {
  "disableWhen": "ninputs(\"mask\") == 0",
  "hideWhen": null
}

    Iterations #

    iterations

    连接遮罩的Mask Aware Blur所用迭代数；普通过滤路径采用各方法固定的轮数。

    类型
    ScalarI64
    默认值
    10
    范围端点
    0 (严格约束) → 1000 (软范围)
    条件与重复行

    参数组: General

    禁用／隐藏条件

    {
  "disableWhen": null,
  "hideWhen": "ch(\"maskaware\") == off || ninputs(\"mask\") == 0"
}

    Method #

    method

    普通路径中blur／boxblur平滑数值，expand／shrink过滤极值，sharpen增强差异；连接遮罩的Mask Aware Blur使用自己的过滤方式。

    类型
    Text
    默认值
    blur
    允许值
    blur / boxblur / expand / shrink / sharpen
    条件与重复行

    参数组: General

    禁用／隐藏条件

    {
  "disableWhen": null,
  "hideWhen": "ch(\"maskaware\") == on && ninputs(\"mask\") != 0"
}

    Radius #

    radius

    世界空间过滤半径，当前要求有限的0–100；零直接传递。连接遮罩的Mask Aware Blur中，非零半径不控制其迭代邻域。

    类型
    ScalarF64
    默认值
    10
    范围端点
    0 (严格约束) → 100 (软范围)
    条件与重复行

    参数组: General

    禁用／隐藏条件

    {
  "disableWhen": null,
  "hideWhen": "ch(\"maskaware\") == on && ninputs(\"mask\") != 0"
}

    Override Border #

    bordertype

    选择网格之外不延伸、使用常量、重复或延展边缘。

    类型
    Text
    默认值
    streak
    允许值
    none / constant / repeat / streak
    条件与重复行

    参数组: General

    禁用／隐藏条件

    {
  "disableWhen": null,
  "hideWhen": "ch(\"maskaware\") == on && ninputs(\"mask\") != 0"
}

    Border Value #

    borderval

    常量边界处理使用的外部值。

    类型
    ScalarF64
    默认值
    0
    范围端点
    0 (软范围) → 10 (软范围)
    条件与重复行

    参数组: General

    禁用／隐藏条件

    {
  "disableWhen": "ch(\"bordertype\") == \"none\"",
  "hideWhen": "ch(\"maskaware\") == on && ninputs(\"mask\") != 0"
}

    Sharpen Strength #

    sharpenstrength

    Method为sharpen时使用的锐化强度。

    类型
    ScalarF64
    默认值
    0
    范围端点
    0 (软范围) → 10 (软范围)
    条件与重复行

    参数组: General

    禁用／隐藏条件

    {
  "disableWhen": null,
  "hideWhen": "ch(\"method\") != \"sharpen\""
}
