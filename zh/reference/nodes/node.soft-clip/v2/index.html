    SoftClip · 节点参考

    围绕指定高度阈值建立柔和过渡，调整地形的高度范围。可以明显改变轮廓，也可以保留更接近原始形态的低强度处理。

    文档版本
    2026-10-19
    节点逻辑版本
    2

    本页对应这个确切的节点逻辑版本。文档打包版本与后端实现版本分别记录。

    输入与输出参数效果示例与验证

    输入与输出

    输入

    1. heightfield_0 必需

      必需的地形高度场。

    2. Threshold 可选

      契约保留可选Threshold端口，但当前实现不读取它；连接贴图不会覆盖标量Threshold参数。

    输出

    1. heightfield_0

      按柔性压缩轮廓及已记录的输出范围行为生成的高度场。

    参数

    契约字段来自有日期的Catalog快照。滑块软范围端点不等于硬验证范围。 数值默认值采用便于阅读的显示精度，精确值保留在可下载契约中。

    Clip ModeThresholdSoftnessClipping

    Clip Mode #

    ClipMode

    AboveThreshold处理高于阈值的山峰；BelowThreshold处理较低区域。

    类型
    选项
    默认值
    AboveThreshold
    允许值
    AboveThreshold / BelowThreshold

    Threshold #

    Threshold

    所选模式的标量高度阈值；当前版本的可选输入不调制此参数。

    类型
    数值（浮点）
    默认值
    0.5
    范围端点
    0 (软范围) → 1 (软范围)

    Softness #

    Softness

    柔性过渡宽度。零不能当作硬裁切的替代：受影响样本遵循已记录的归零边界行为。

    类型
    数值（浮点）
    默认值
    0.1
    范围端点
    0 (软范围) → 1 (软范围)

    Clipping #

    Clipping

    控制过渡之外的压缩程度；建议固定阈值并保持非零Softness后比较。

    类型
    数值（浮点）
    默认值
    1
    范围端点
    0 (软范围) → 1 (软范围)
