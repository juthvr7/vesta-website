    参数

    契约字段来自有日期的Catalog快照。滑块软范围端点不等于硬验证范围。 数值默认值采用便于阅读的显示精度，精确值保留在可下载契约中。

    Name AttributeClassGroup PrefixConflict OpInvalid Names

    Name Attribute #

    attribname

    读取的字符串属性名称；属性缺失或类型不兼容时产生警告并传递原几何。

    类型
    Text
    默认值
    name

    Class #

    class

    选择图元、点或顶点属性，结果组位于相同元素域。

    类型
    Text
    默认值
    primitive
    允许值
    primitive / point / vertex

    Group Prefix #

    groupprefix

    给每个属性值添加前缀，再检查结果组名是否合法。

    类型
    Text
    默认值

    Conflict Op #

    conflict

    遇到同名组时，替换成员或与已有成员取并集。

    类型
    Text
    默认值
    replace
    允许值
    replace / union

    Invalid Names #

    invalidnames

    忽略非法名称、规范化名称或进行编码；空源字符串不创建组。

    类型
    Text
    默认值
    forcevalid
    允许值
    ignore / forcevalid / encode
