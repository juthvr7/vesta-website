    输入与输出参数 (2)效果示例与验证

    使用提示

    • 手动校正使用量化曲线，自动校正使用连续输入值。允许有限的负值和HDR样本，最终输出归一化到零至一。
    • 自动模式逐通道独立校正，而不是使用一条亮度曲线，因此可能改变色彩平衡。
    • 灰度图保持灰度，RGB保持RGB；RGBA输入移除Alpha后输出RGB，不预乘颜色。Alpha不作为遮罩，透明像素的颜色值也会参与计算。
    • 下方示例展示地形输出；彩色图像控件与传输另有验证，不把地形渲染图当作图像输入或GPU证据。

    输入与输出

    输入

    1. heightfield_0 Geometry 必需

      一路必需的Geometry输入，承载单个高度场或类型明确的Gray／RGB／RGBA图像；任意体积、网格和混合图元容器会被拒绝。

    输出

    1. heightfield_0 Geometry

      校正后的高度场或图像。保留高度场附加图层及图像身份／网格元数据；RGBA转换为RGB。

    参数

    契约字段来自有日期的Catalog快照。滑块软范围端点不等于硬验证范围。 数值默认值采用便于阅读的显示精度，精确值保留在可下载契约中。

    GammaValue

    关闭Automatic时显示的手动曲线控制：一保留归一化明暗，零输出全黑，零到一之间压低中间值，大于一抬高中间值。切换自动模式会保留手动值。

    类型
    ScalarF64
    默认值
    0.44
    范围端点
    0 (软范围) → 4 (软范围)
    条件与重复行

    参数组: General

    禁用／隐藏条件

    {
  "disableWhen": null,
  "hideWhen": "{ Automatic == 1 }"
}

    Automatic #

    Automatic

    根据输入算术均值确定曲线；对非退化的归一化通道，该输入值映射到二分之一。RGB各通道分别计算，GammaValue隐藏且不参与计算。全黑通道在此零均值边界下会变为全白。

    类型
    Bool
    默认值
    false
    条件与重复行

    参数组: General
