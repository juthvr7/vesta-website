    Fold · 节点参考

    通过正弦、三角与锯齿曲线折叠高度。同一片起始地形，在重复与对称之间呈现不同形态。

    文档版本
    2026-10-19
    节点逻辑版本
    2

    本页对应这个确切的节点逻辑版本。文档打包版本与后端实现版本分别记录。

    输入与输出参数效果示例与验证

    输入与输出

    输入

    1. heightfield 必需

      必需的地形高度场。

    2. folds 可选

      可选的逐样本频率调制；网格分辨率必须与地形一致，它不是结果透明度遮罩。

    输出

    1. heightfield_0

      经过所选波形重映射的高度值。

    参数

    契约字段来自有日期的Catalog快照。滑块软范围端点不等于硬验证范围。 数值默认值采用便于阅读的显示精度，精确值保留在可下载契约中。

    WaveformFoldsSymmetric

    Waveform #

    Waveform

    选择Sine、Triangle或Sawtooth。效果研究以同一地形和显示处理比较三种波形。

    类型
    选项
    默认值
    Sine
    允许值
    Sine / Triangle / Sawtooth

    Folds #

    Folds

    控制高度范围内的波形频率；可选第二输入会逐样本调制该频率。

    类型
    数值（浮点）
    默认值
    2
    范围端点
    0 (软范围) → 10 (软范围)

    Symmetric #

    Symmetric

    折叠前围绕高度中点偏移波形输入，改变轮廓对齐方式，不是混合结果的开关。

    类型
    开关
    默认值
    开启
