    Group Copy

    把参考输入的分组成员映射到第一输入，不替换第一输入的几何；第二输入提供分组与对应关系。

    文档版本
    2026-10-19
    节点逻辑版本
    2

    本页对应这个确切的节点逻辑版本。文档打包版本与后端实现版本分别记录。 保留全部已声明参数；行为说明和效果媒体分别记录完成状态。

    输入与输出参数 (20)效果示例与验证

    使用提示

    • 两路Geometry输入都必需；成员映射、空组和名称冲突分别控制。

    输入与输出

    输入

    1. geometry Geometry 必需
    2. reference Geometry 必需

    输出

    1. geometry Geometry

    Enable Primitive Groups #

    primitives

    启用从参考输入向第一输入复制图元组。

    类型
    Bool
    默认值
    true

    Primitive Groups #

    primgroups

    选择参考输入的图元组名称；空模式选择此元素域的全部组。

    类型
    Text
    默认值
    条件与重复行

    禁用／隐藏条件

    {
  "disableWhen": "{ primitives == 0 }",
  "hideWhen": null
}

    Primitive Group Prefix #

    primnameprefix

    在处理同名冲突前，为复制的图元组名称添加前缀。

    类型

    默认值
    条件与重复行

  "hideWhen": null
