04 / Platform advantage

Designed as infrastructure,
experienced as a creative tool.

TYPE / 01

A unified graph language

SOP geometry, heightfields, raster processing, and spatial composition share one typed model instead of isolated runtimes.

SCALE / 02

Spatial and incremental by design

Bounded evaluation, tiles, LOD, content-addressed caching, and cooperative cancellation are part of the execution contract.

HOST / 03

Engine independence without drift

Studio, CLI, Worker, and engine adapters enter the same operation chain. Adapters translate data; they do not reinvent semantics.

COMPUTE / 04

CPU certainty, GPU acceleration

A deterministic CPU reference establishes behavior first. Explicit backend segments unlock GPU performance without changing the graph.
